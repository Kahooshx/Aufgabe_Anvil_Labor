## Projektbeschreibung: Chemielabor-Verwaltungssystem

In diesem Projekt wurde ein System zur Verwaltung eines Chemielabors geplant und umgesetzt. Dabei ging es darum, typische Abläufe im Labor – wie Experimente, eingesetzte Chemikalien, Mitarbeiter und Sicherheitsunterweisungen – übersichtlich zu organisieren.
